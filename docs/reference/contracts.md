## Rules every contract follows

- A contract changes only by a new version: a major bump for a breaking change, a minor bump for an additive one, and the old version stays until no producer emits it. After the freeze, contracts evolve only additively (plan decision 23).
- Producers validate what they write and consumers what they read, with `python batuta.py contract validate <id> <file>`; CI lints every schema and fixture with `python batuta.py contract lint`.
- The schema dialect is a restricted JSON Schema draft 2020-12; the validator refuses a schema that uses anything outside it. See `plugins/batuta/contracts/README.md` for the dialect, the sections files of the Markdown contracts and the fixture rules.
