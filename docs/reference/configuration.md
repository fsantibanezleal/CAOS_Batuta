# Configuration reference

Generated by `scripts/gen_reference.py` from the C01 schema (`plugins/batuta/contracts/C01-batuta-config.schema.json`) and the built-in defaults of `batuta_lib/config.py`; do not edit by hand. `tests/test_docs_reference.py` fails when this page differs from the code.

`batuta.json` is a C01 document (contract version 1.1). It is found in this order: `--config PATH`, `$BATUTA_CONFIG`, the project file `.batuta/batuta.json`, the user file `<BATUTA_HOME>/batuta.json`, then the built-in defaults. `$VAR` and `${VAR}` expand from the environment before validation, so a variable cannot smuggle in a path that C01 refuses. A field that holds an environment variable NAME (`credential_env`, `endpoint_env`) is never expanded.

## Keys

The Default column is the value of the built-in defaults when no file exists; `none` means the key is optional and absent by default. Keys the schema does not list are allowed (`additionalProperties`), which is how the areas read their own optional keys (next section).

| Key | Type | Required | Default | Description |
|---|---|---|---|---|
| `contract_version` | string: 1.0, 1.1 | yes | `1.0` | 1.0 documents stay valid; 1.1 adds the optional tdd block (the `tdd` definition, applied to 1.1 documents only). |
| `version` | integer (min 1) | no | `1` | Optional integer version of the document layout. |
| `roots` | object | yes | object | The three device roots, by role. Values are paths or `$VAR` references; never a drive letter or user path. |
| `roots.temp` | string (min length 1) | yes | `<BATUTA_HOME>/temp` | Root for temporary files. An unset `$VAR` falls back to `<BATUTA_HOME>/temp`. |
| `roots.data` | string (min length 1) | yes | `<BATUTA_HOME>/data` | Root for data and downloads. An unset `$VAR` falls back to `<BATUTA_HOME>/data`. |
| `roots.worktrees` | string (min length 1) | yes | `<BATUTA_HOME>/worktrees` | Root for git worktrees. An unset `$VAR` falls back to `<BATUTA_HOME>/worktrees`. |
| `roles` | object | yes | object | One entry per agent role; `route check` compares each agent file with the role of the same name. |
| `roles.<role>` | object | no | see the role table below | The model and effort of one role. |
| `roles.<role>.model` | string: haiku, sonnet, opus, fable, inherit | yes | see the role table below | The model alias or id the role runs on: `haiku`, `sonnet`, `opus`, `fable` or `inherit`. |
| `roles.<role>.effort` | string: low, medium, high, xhigh | yes | see the role table below | The reasoning effort: `low`, `medium`, `high` or `xhigh`. |
| `roles.<role>.omit_claude_md` | boolean | no | see the role table below | When true the agent file must carry `omitClaudeMd: true`, so the role does not load CLAUDE.md. |
| `caps` | object | yes | object | Limits on delegation, read by `route`, `brief` and `dispatch`. |
| `caps.max_concurrent_agents` | integer (min 1) | yes | `4` | Most agents running at once. |
| `caps.max_agents_per_task` | integer (min 1) | yes | `8` | Most agents launched for one task. |
| `caps.max_opus_reviews_per_task` | integer (min 0) | yes | `1` | Most reviews on the strongest model per task. |
| `caps.spawn_depth` | integer (min 0) | yes | `1` | How deep a subagent may spawn subagents; the settings preset exports it as `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`. |
| `caps.max_cost_usd_per_task` | number (min 0) | no | none | Budget cap per task in US dollars for the dispatch lanes that bill (sdk, provider). |
| `gates` | object | yes | object | Which gates are critical and which model each kind of gate uses for its independent check. |
| `gates.critical` | array of string: L0-understand, L1-size, L2-decide, L3-contracts, L4-boundaries, L5-freeze, L6-skeleton, L7-build, L8-integrate, L9-promote, L10-lessons | yes | `["L2-decide", "L5-freeze", "L9-promote"]` | Gates that use the critical (reviewer) model. Default: L2-decide, L5-freeze, L9-promote. |
| `gates.adversary_model_critical` | string: haiku, sonnet, opus, fable, inherit | yes | `opus` | Model of the reviewer that checks a critical gate. |
| `gates.adversary_model_routine` | string: haiku, sonnet, opus, fable, inherit | yes | `sonnet` | Model of the adversary that checks every other gate. |
| `gates.critical_units` | array of string (pattern) | no | `[]` | Unit ids marked critical: their L7-build gate is critical too. |
| `coordination_root` | string (pattern) | no | `.batuta` | Relative path of the folder that holds briefs, ledger and state (`delegation/ledger.md` lives under it). |
| `knowledge_manifest` | string (pattern) | no | `.batuta/knowledge/manifest.json` | Relative path of the knowledge manifest (C12) read by `context build`. |
| `user_core` | object | no | object | the template the device area renders into the user's always-loaded core, and its placeholder values |
| `user_core.template` | string (pattern) | yes | none | Path, relative to the deploy root, of the template rendered into the user's always-loaded core. |
| `user_core.values` | object of string | no | none | Placeholder name to string, filled into the template. |
| `budgets` | object | yes | object | Byte and line limits of what loads at every session start (C14); `context check` enforces them. |
| `budgets.user_core_bytes` | integer (min 0) | yes | `7000` | Most bytes of the user-level core. |
| `budgets.project_core_bytes` | integer (min 0) | yes | `7000` | Most bytes of the project CLAUDE.md chain. |
| `budgets.unscoped_rules_bytes` | integer (min 0) | yes | `2000` | Most bytes of rule files that carry no `paths` front matter. |
| `budgets.memory_index_bytes` | integer (min 0) | yes | `4000` | Most bytes of a memory index (MEMORY.md). |
| `budgets.memory_index_lines` | integer (min 0) | yes | `60` | Most lines of a memory index (MEMORY.md). |
| `dispatch` | object | no | object | Where a brief runs (C30). Providers map a name to environment variable NAMES, never to values. |
| `dispatch.default_lane` | string (pattern) | yes | `subagent` | subagent, sdk, or provider:<name> with <name> a key of dispatch.providers. |
| `dispatch.lanes` | array of string (pattern) | yes | `["subagent"]` | The enabled lanes: `subagent`, `sdk` or `provider:<name>`. |
| `dispatch.providers` | object | no | object | Provider name to provider settings; credentials are environment variable names, never values. |
| `dispatch.providers.<name>` | object | no | none | One provider, referenced by a lane as `provider:<name>`. |
| `dispatch.providers.<name>.kind` | string: anthropic, openai-compatible, gemini, bedrock, vertex | yes | none | The adapter: `openai-compatible`, `gemini`, `bedrock` or `vertex` (`anthropic` for the sdk lane's credential). |
| `dispatch.providers.<name>.credential_env` | string (pattern) | yes | none | Name of the environment variable that holds the credential, never the credential. |
| `dispatch.providers.<name>.endpoint_env` | string (pattern) | no | none | Name of the environment variable that holds the endpoint URL. |
| `dispatch.sdk` | object | no | none | Settings of the sdk lane. |
| `dispatch.sdk.key_file` | string (min length 1) | no | none | Path of a file that holds the Anthropic API key for the sdk lane (the path, never the key; `$VAR` expands). Without it the lane reads ANTHROPIC_API_KEY. |
| `tdd` | object | no | object | Optional settings of the tdd area, closed, checked (as `tdd` of the document) only when contract_version is 1.1; every key is optional and an absent key means the tool's default. A 1.0 document may carry any `tdd` value, as the open root always allowed. `lock_file` also ends in .json and is never batuta.json (semantic check). |
| `tdd.test_command` | string (min length 1) | no | `python -m unittest discover -s tests -p "test_*.py" -v (with '-t .' added when 'tests' is a package)` | The command `tdd` replays to run the project's tests, as one string (for example `python -m unittest`). |
| `tdd.replay_timeout_seconds` | integer (min 1) | no | `300` | Seconds the replay of the test command may run before it is stopped. The tool's default applies when absent. |
| `tdd.lock_file` | string (pattern) | no | `.batuta/test-locks.json` | Relative path of the test lock file (C07) inside the repository. Default `.batuta/test-locks.json`. |
| `tdd.markers` | array of string (min length 1) | no | `the built-in list of every language` | Names of extra weakening markers that `tdd check` looks for. They add to the default list of every language; a default marker cannot be removed. |

## Keys read by areas that C01 does not declare

Source: `docs/reference/enforcement-matrix.md`. Every key is optional; a missing key keeps the default.

| Key | Read by | Default | Meaning |
|---|---|---|---|
| `tdd.lock_file` | `guard-locked-tests`, tdd area | `.batuta/test-locks.json` | Relative POSIX path of the test lock file; no `..`. |
| `guards.secret_globs` | `guard-secrets` | built-in list (environment files, keys, certificates, credentials) | Extra globs of files an agent never reads. |
| `guards.protected_branches` | `guard-destructive` | `main`, `master`, `develop`, `release/*` | Extra protected branch names or globs. |
| `guards.destructive_disable` | `guard-destructive` | none | Names of destructive packs to switch off. |
| `guards.require_brief` | `guard-require-brief` | `deny` | `deny`, `ask` or `off`: what happens to an Agent launch without a valid brief. |
| `guards.scan_ignore` | `guard scan` | `**/*.md` | Globs the scan skips; read from the base revision of the scanned range. |
| `leaks.allow_emails` | `leaks scan` | the built-in non-personal addresses | Extra e-mail patterns the scan accepts. |

## Environment variables

| Variable | Use |
|---|---|
| `BATUTA_HOME` | The user folder of Batuta: user `batuta.json`, the device copy and the fallback roots. Default `~/.batuta`. |
| `BATUTA_CONFIG` | Path of a `batuta.json` that wins over the project and user files. A path that does not exist is an error. |
| `BATUTA_TEMP` | Usual value of `roots.temp` (`$BATUTA_TEMP`). Unset falls back to `<BATUTA_HOME>/temp`. |
| `BATUTA_DATA` | Usual value of `roots.data` (`$BATUTA_DATA`). Unset falls back to `<BATUTA_HOME>/data`. |
| `BATUTA_WORKTREES` | Usual value of `roots.worktrees` (`$BATUTA_WORKTREES`). Unset falls back to `<BATUTA_HOME>/worktrees`. |
| `BATUTA_PYTHON` | Python interpreter the npx entry uses before it tries `py -3`, `python3` and `python` (changes/u9b-plugin-readme.md). |
| `BATUTA_LEAKS_DENY_LIST` | Path of the private deny-list file of `leaks scan`, outside the repository (docs/reference/enforcement-matrix.md). |
