# Command line reference

Generated by `scripts/gen_reference.py` from the argparse parsers of the dispatcher (`plugins/batuta/scripts/batuta.py`); do not edit by hand. `tests/test_docs_reference.py` fails when this page differs from the code.

Every command is `python batuta.py <area> <verb> [arguments]`. The dispatcher imports every module of `batuta_lib/areas/`; a module that fails to load is reported as `WARN area <name> failed to load: <error>` and skipped.

## Index

- `adr`: Architecture decisions: new ADR from the template, lint the lifecycle.
- `brief`: Delegation briefs: create one from the template (with its ledger row) and lint it before launch.
- `context`: Context budget: build the knowledge index and core, check and measure what loads at session start.
- `contract`: Data contracts: lint schemas, fixtures and a project's artifacts, validate an artifact, compute parallel waves.
- `device`: Device: deploy the device copy, restore settings with verification, check at session start, back up learned state.
- `dispatch`: Dispatch: plan where a brief runs (subagent, Agent SDK, provider), run it under cost and time caps, resume it.
- `fragments`: Fragments: merge per-unit changelog bullets and i18n rows into the shared files.
- `gate`: Gates: evidence lint, status, gate check, ratcheting thresholds, promotion on green, Stop hook.
- `guard`: Guardrails as hook handlers: automation, locked tests, approvals, secrets, destructive commands, briefs.
- `init`: Adopt Batuta: init user and init project, then doctor, update and uninstall.
- `leaks`: Public hygiene: scan tracked files for user paths, e-mail addresses, tokens and private deny-list terms.
- `lessons`: Lessons: every unit with a passed build has a dated lesson in LESSONS.md.
- `memory`: Auto-memory: regenerate a project's MEMORY.md as a short index plus topic pages.
- `preflight`: Preflight: machine limits (CPU, memory, disk, GPU, Python, Node) and owner-prerequisite probes.
- `provider`: Providers: declared availability states with tests (lint) and runtime availability blocks (check).
- `report`: Reports: check a report against its brief, update the ledger status, hold an agent until its report passes.
- `reserve`: Reservations: sequence numbers reserved under a lock before parallel units start.
- `route`: Roles and models: show the routing table, check the agent files against it.
- `size`: System sizing: lint sizing.md against C23 and the contract catalog, with estimate totals.
- `skeleton`: Walking skeleton: readiness document, provider labels, contract tests and previews.
- `spec`: Specs: new, lint, trace, show, approve (typed, hash-bound), freeze --check.
- `tdd`: Test-first on artifacts and history: test lock, red and green commits, history check and replay.
- `tech`: Technology matrix: pinned, sourced and fresh versions; decisions with spikes.
- `version`: show Batuta version

| Argument | Required | Type | Default | Description |
|---|---|---|---|---|

| `--json` | no | flag | none | machine-readable output |
| `--version` | no | flag | none | show program's version number and exit |

## Output and exit codes

Every area prints tag-prefixed lines, then a summary; with `--json` it prints the C20 object (`contract_version`, `tool`, `area`, `verb`, `exit_code`, `items`, `summary`).

Tags: `OK`, `NEW`, `CHANGED`, `SAME`, `SKIP`, `MERGED`, `REMOVED`, `MISSING`, `DIFFERENT`, `REFUSED`, `WARN`, `FAIL`.

Exit code 0 is ok, 1 is a failure or refusal (any `FAIL` or `REFUSED` item, and also a usage error), and 2 is warnings or an honest partial (any `WARN` item). A write is a dry run unless `--apply` is given.

```
batuta.py brief new --slug SLUG --topic TOPIC --agent {adversary,doc-writer,implementer,reviewer,runner,searcher,test-author,general-purpose} --title TITLE [--model {haiku,sonnet,opus,fable}] [--kind {implement,job,skeleton,docs,review,research,lookup,run}] [--sizing SIZING] [--report REPORT] [--root ROOT] [--date DATE]
```

| Argument | Required | Type | Default | Description |
|---|---|---|---|---|

| `--topic TOPIC` | yes | str | none | short kebab-case topic; the id is <topic>-<date> |
| `--agent {adversary,doc-writer,implementer,reviewer,runner,searcher,test-author,general-purpose}` | yes | one of adversary, doc-writer, implementer, reviewer, runner, searcher, test-author, general-purpose | none | the agent that runs it |

| `--model {haiku,sonnet,opus,fable}` | no | one of haiku, sonnet, opus, fable | none | override the agent's pinned model (an escalation) |
| `--kind {implement,job,skeleton,docs,review,research,lookup,run}` | no | one of implement, job, skeleton, docs, review, research, lookup, run | none | the brief kind (default: from the agent) |
| `--sizing SIZING` | no | str | none | path of the product's sizing document, written into the brief header |
| `--report REPORT` | no | str | none | report path inside the project root (default: next to the brief) |
| `--root ROOT` | no | str | `.` | project root (default: the current folder) |
| `--date DATE` | no | str | none | ISO date for the id (default: today) |

## Area `dispatch`

Dispatch: plan where a brief runs (subagent, Agent SDK, provider), run it under cost and time caps, resume it. Owner unit: U13.

### `dispatch plan`

Validate a brief and a lane, write the C30 request.

```
batuta.py dispatch plan --brief BRIEF [--lane LANE] [--model MODEL] [--max-cost MAX_COST] [--max-turns MAX_TURNS] [--timeout-s TIMEOUT_S] [--report-only] [--allow-unpriced] [--out OUT] [--no-write] [--root ROOT]
```

| Argument | Required | Type | Default | Description |
|---|---|---|---|---|
| `--brief BRIEF` | yes | str | none | the brief file (C02) |
| `--lane LANE` | no | str | none | subagent, sdk or provider:<name> (default: dispatch.default_lane) |
| `--model MODEL` | no | str | none | the model id (required for a provider lane; default: the role's model) |
| `--max-cost MAX_COST` | no | float | none | the cost budget in USD (never above caps.max_cost_usd_per_task) |
| `--max-turns MAX_TURNS` | no | int | none | turn limit (default: from the brief's budget line) |
| `--timeout-s TIMEOUT_S` | no | int | none | time limit in seconds (default 3600) |
| `--report-only` | no | flag | none | a tool-less lane returns a report only, never a patch |
| `--allow-unpriced` | no | flag | none | run a model without a verified price (the cap cannot be enforced) |
| `--out OUT` | no | str | none | where to write the request (default: next to the brief) |
| `--no-write` | no | flag | none | print the request without writing it |
| `--root ROOT` | no | str | `.` | project root (default: the current folder) |
