- Area `dispatch` (contract C30): `dispatch plan` validates a brief and a lane against the configuration and writes the request; `dispatch run` is a dry run by default and `--apply` executes the lane under a monotonic time limit and the per-task cost cap (`caps.max_cost_usd_per_task`); `dispatch resume` continues the saved Agent SDK session of an unfinished result within the cap that is left. Every run writes a C30 result and a ledger row (Model, Provider, Tokens in, Tokens out, Cost USD, Status) through `delegation.update_ledger`.
- Lanes: `subagent` returns the exact launch specification for the main session and never claims to have launched anything (the result is `pending`); `sdk` drives the Claude Agent SDK on an API key (the package is imported lazily and the lane refuses with the install command when it is missing), runs the batuta guards through the C31 launcher as the PreToolUse policy, adds a write-scope check for write tools, runs the brief's checks itself before marking the result complete and sends a failure back to the agent for at most two rounds; `provider:<name>` makes one tool-less call and returns a report and an optional patch that is written next to the report and applied only after the gates.
- Provider adapters over a pluggable standard-library HTTPS transport: `openai-compatible` (OpenAI, Azure OpenAI, vLLM, a LiteLLM gateway, Ollama), `gemini`, `bedrock` (Converse) and `vertex` (Claude `rawPredict`). Retries on 429, 5xx and connection errors are bounded (at most four, exponential backoff with jitter, `Retry-After` honoured up to 60 s, never past the deadline); `--transport-fixture FILE` replays answers from a file with no network.
- Cost caps and prices: `batuta_lib/dispatch/prices.json` lists USD per million tokens by provider and model with the source URL and the date read; an unverified or missing price refuses a paid lane unless `--allow-unpriced` is given. The output budget of a call is bounded by what the cap still buys, a projected cost over the cap stops the run before anything is sent, and an answer that costs more than the cap is discarded and recorded as `over-budget` with its partial cost.
- Credentials are read at call time from the environment variable named in `batuta.json` (or the `dispatch.sdk.key_file` of the sdk lane), never written to disk or printed: every output, result, report note and ledger cell passes through a redactor that masks the value, its JSON and URL encodings, common token shapes and credential headers. A provider patch outside the brief's write scope is refused, and a brief whose kind needs tools (implement, job, skeleton, run) is refused on a provider lane unless `--report-only` is given.
