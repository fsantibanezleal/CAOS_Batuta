- End-to-end self-test (`tests/e2e/`): a scratch world (temporary home, device copy, git repository with a local bare remote) drives the public command line and the hook payloads through the whole governed lifecycle (init user, init project, size and catalog, spec, typed approval, freeze, red and green commits, replay, evidence, gates, Stop hook, promotion), validates every artifact it writes against its contract, and shows each refusal (a brief with an unfilled slot, a wrong approval prefix, an edit of a locked test, a green commit touching a locked path, a weakened test, a gate without evidence, a promotion without a green head, an automation command, a secret-shaped string). The device, project, plugin, npx and copier channels are each tested; a missing `claude`, Node or copier skips only its channel with the reason printed, a missing git fails the suite.
- CI: a new `e2e` job runs the package on Linux and Windows, Python 3.10 and 3.13.
