- Area `route`: `route show` prints the role table (role, model, effort, omit_claude_md) from the configuration (C01); `route check` validates the configuration, every agent file in `plugins/batuta/agents/` against C18, that an agent's model equals its role's model, and that every agent whose role runs on Haiku carries `omitClaudeMd: true`. Without a configuration file the C01 defaults apply, announced by a WARN line on stderr.
- Area `brief`: `brief new` writes a brief from `templates/brief.md` (the contract-first sections for implement, job and skeleton) and adds its row to `<coordination_root>/delegation/ledger.md`, created with the C04 header when absent, existing rows and optional columns kept byte for byte, ids that collide on a day suffixed `-2`, `-3`; `brief lint` applies C02 plus the rules a schema cannot hold (unfilled slots, escalation, the fable model, more than eight deliverables, a write scope that overlaps another open brief of the ledger).
- Area `report`: `report check` applies the report checker (one Completeness row per deliverable, status DONE, PARTIAL or BLOCKED, evidence, no placeholders in prose, Sources for research and docs, Red run before Green run for implement briefs, Production path when the brief asks) and C03, with exit 0 complete, 1 defective, 2 honest PARTIAL or BLOCKED; `report ledger-status [--write]` recomputes the Status column of the ledger from the reports (drafted becomes pending, a deleted report becomes lost, accepted and dispatch outcomes are kept).
- SubagentStop decision in the `report` area (`HOOKS["subagent-stop"]`, with the command-line twin `report hook-subagent-stop`): a briefed agent without its BRIEF and REPORT lines, or whose report is missing, defective or has open rows, is blocked once with the exact problems; an unbriefed agent is allowed; a second attempt is allowed and appends a dated UNVERIFIED line to `<coordination_root>/delegation/unverified.log`, so the hook never loops; any internal error allows the stop with a stderr line.
- Shared module `batuta_lib/delegation.py`: roles and kinds, the brief template renderer, the lint, Markdown section helpers and the ledger (read, add a row, set a status, all byte-stable; `update_ledger` is atomic under a lock file, re-reads the ledger before the replace so a concurrent row is kept, and refuses a result that does not satisfy C04).
- Agents: `searcher` and `runner` (Haiku, low effort, `omitClaudeMd: true`), `implementer` and `doc-writer` (Sonnet, medium), `reviewer` (Opus, high), each with the shared delegation contract and no `hooks` key; the plugin's hooks file wires the SubagentStop decision.
- Hardening after the adversary check: `brief lint` counts sections, deliverables and check commands outside code fences only and holds every check bullet to a backticked command; `brief new` picks the id and creates the brief with an exclusive create inside the ledger lock and removes only its own file; a lock timeout and a multi-line title have their own refusals; `report ledger-status` never downgrades an accepted or lost row; the SubagentStop decision keeps its own once-per-agent state and finds the project root and its configuration above the payload cwd.
