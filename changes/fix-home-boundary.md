- Fix: no search for a project root climbs to the user's home or above it. One shared helper (`batuta_lib/projectroot.py`, `ascend` and `find`) serves the guards, the delegation and SubagentStop hook root, the gate Stop handler and the device profile; a folder `<home>/.batuta`, a `.git` or a `specs` folder of the home is never a project marker, whatever `BATUTA_HOME` says, and a missing marker falls back to the working directory. Before, a hook run from a folder below a home that held `.batuta` wrote `unverified.log` into the home.
- Test suite: a real-home guard (`tests/_home_guard.py`, installed by `tests/test_00_home_guard.py`) points `HOME`, `USERPROFILE` and `Path.home` at a temporary home for the whole run and fails, by test name, any test that changes the real home or writes into the home default.
- Template: the project template ships a `.gitignore` that excludes `.batuta/delegation/`, and its `AGENTS.md` and `CLAUDE.md` say delegation records carry machine paths and belong in a private coordination repository, so `leaks scan` of a rendered project stays clean after `brief new`.
